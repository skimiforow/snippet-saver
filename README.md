# Snippet Saver: website

Home page and privacy policy of the Snippet Saver Chrome extension, published with GitHub Pages:

- https://skimiforow.github.io/snippet-saver/
- https://skimiforow.github.io/snippet-saver/privacy.html

Static HTML and CSS, no build step. `privacy.html` mirrors `store/privacy-policy.md` in the extension's
(private) repository: change both together.
